# Lean Build Log

A single-page workout log and five-day hybrid lifting program, built to install on a phone home screen and run offline.

- No account and no server. Workouts are stored in the browser on the device. Use Settings, Back up to save a file.
- Plain HTML, CSS and JavaScript in `index.html`. No build step.
- Exercise photos in `demo/` come from [free-exercise-db](https://github.com/yuhonas/free-exercise-db), which is released into the public domain.
